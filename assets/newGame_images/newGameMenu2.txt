|  умений, полезные как в бою, так и при других ситуациях.                                                                       +
|  * БАРД - мастер игры музыки, с помощью своего инструмента он может творить магию, а с помощью мелодии воодушевлять командуй   |
|  или сражаться. Кастер через ХАРИЗМУ.                                                                                          |
|  * ВАРВАР - могущественный и сверепый воин, пологающийся на физическую силу, а главной его фишкой является ярость при которой  |
|  он получает сильные бонусы. Не кастер, пологается на СИЛУ                                                                     |
|  * ВОИН - мастерский боец, владеющий всеми оружиями и доспехами, с помощью второго дыхания он может спасти себя в критические  |
|  моменты. Не кастер, пологается на СИЛУ или ЛОВКОСТЬ.                                                                          |
|  * ВОЛШЕБНИК - с первых уровней самый слабый кастер, однако с повышением уровеня он становится более сильнее и потенциальнее   |
|  чем другие кастеры. Его магическая книга может содержать сколько угодно заклинаний, что может дать ему доступ почти ко всем   |
|  заклинаниям мира. Кастер через ИНТЕЛЕКТ.                                                                                      |
|  * ДРУИД - класс, который взаимодействует с окружающей природой, его заклинания связаны с природой и ее взаимодействием,       |
|  так же обладает языком присущий только друидам, что дает возможность читать древние письменностьи на стенах. Кастер через     |
|  МУДРОСТЬ.                                                                                                                     |
|  * ЖРЕЦ - персонаж, взявший этот класс, осваивает заклинание связанные с божественной силой. Один из классов, получающий       |
|  подкласс с первого уровня.
